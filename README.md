# ⚖️ NyayaAI

> **AI-powered legal information & document assistant.**

NyayaAI helps users explore general legal information, ask questions, save conversations, and review documents using AI.

### ✨ Features

- 🤖 AI-powered legal chat
- 🌐 English, Hindi & Hinglish
- 💬 Chat history
- 📄 PDF, DOCX, TXT & MD support
- 🔍 AI-assisted document review
- 🔐 User authentication
- 📚 Legal information library

### 🛠️ Built With

**Python · Flask · Google Gemini · SQLite · HTML · CSS · JavaScript**

### 🚀 Quick Start

```bash
git clone https://github.com/Madhukar2006/NyayaAI.git
cd NyayaAI
pip install -r requirements.txt
python app.py
```

Create a `.env` file:

```env
GEMINI_API_KEY=your_api_key
SECRET_KEY=your_secret_key
```

### ⚠️ Disclaimer
